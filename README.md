🚀 From Manual Work to Cloud Automation – My First Real-World Data Project
While working part-time at a convenience store in the UK, I noticed a recurring challenge:
Every week, inventory invoices worth thousands of pounds had to be calculated manually.
This process:
- Took hours of effort
- Required multiple employees
- Was prone to human error
I started asking a simple question:
👉 Can this be automated?
Initially, I proposed using Python and PostgreSQL to process and store the data.
But this raised important concerns from management:
- Where will we securely store the files?
- Do we need to write SQL queries every time to analyze data?
- How do we protect sensitive invoice information (£10,000+ per file)?
- Who should have access to this data?
At that point, I didn’t have all the answers.
That’s when I started exploring Amazon Web Services.
After 4 months of continuous learning and hands-on work, I built a complete data pipeline:

📂 File Upload → ☁️ Cloud Storage → ⚙️ Automated Processing → 🗄️ Database → 📊 Dashboard

Using:
- Amazon S3 for secure file storage
- Amazon SQS for event-driven processing
- Python for data extraction and automation
- Amazon RDS with PostgreSQL for structured storage
- Tableau for automated dashboards

✅ Impact
- Reduced manual workload of 3 employees
- Improved accuracy and consistency
- Enabled historical comparison of inventory data
- Delivered real-time insights through dashboards
- Visualized current purchase trends clearly
- Identified which product categories generate the highest profit
- Compared current purchases with previous cycles to highlight changes and patterns
